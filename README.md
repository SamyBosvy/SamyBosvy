- **Redress** *(in progress)*: a complaints-management platform for EU payment and e-money institutions, built on my experience as EU/UK Complaints Manager at Square/Block. Multi-tenant with row-level security. Built so far: complaint intake and a public web form per firm, PSD2 business-day deadline clocks per customer country (15 days, 35 with a holding response), a colour-coded queue, responses generated from templates with the ADR referral built in, a database-enforced audit trail, QA review with random sampling, a reporting dashboard with a regulatory pack, and GDPR retention and subject-access tools. Next: billing and email notifications.
